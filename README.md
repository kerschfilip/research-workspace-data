# Derived text formats and full exports for the Research Workspace

Interactive overview of derived text formats (DTF) and full export formats
proposed for the Research Workspace of the ELC-DHLR project (WP3):
descriptions, examples computed from sample data, manifest, JSON Schemas and
implementation rules. Czech and English.

- Web: https://kerschfilip.github.io/research-workspace-data/
- `data-samples/`: one publication (*Eugenické a kulturní úkoly ženy*, 1928)
  exported by this proposal (`suggestion`), by the current Research Workspace
  and by DL4DH.
